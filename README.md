# Tic-Tac-Toe

A small, responsive two-player Tic-Tac-Toe game built with plain HTML, CSS, and JavaScript. It runs entirely in a browser—no installation, build process, or dependencies are required.

## Files

- `index.html` — the game interface
- `style.css` — responsive visual design and animations
- `script.js` — turn handling, winner detection, and scorekeeping

## Run it

Open `index.html` in any modern web browser. You can double-click the file or use an editor's live-preview feature.

## How to play

1. Player X takes the first turn; players alternate selecting open squares.
2. Make a horizontal, vertical, or diagonal row of three marks to win a round.
3. **New round** clears the board while keeping the scoreboard.
4. **Reset scores** clears both the board and all recorded scores.
